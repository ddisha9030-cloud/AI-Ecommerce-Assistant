# AI E-Commerce Assistant

An AI-powered personalized e-commerce platform that helps users discover products based on their preferences, requirements, budget, restrictions, and context.

## Project Goal

To build an intelligent shopping assistant that understands natural-language user requirements and provides personalized, explainable, and constraint-aware product recommendations.

## Planned Features

- AI Shopping Assistant
- Personalized Product Recommendations
- Budget-Based Product Filtering
- Allergy / Ingredient Warnings
- AI Gift Finder
- Product Comparison
- Feedback-Based Recommendation Refinement

## Technology Stack

- Frontend: React.js
- Backend: Python + FastAPI
- Database: PostgreSQL
- AI/NLP: To be implemented
- Machine Learning: Python / Scikit-learn
- Version Control: Git + GitHub
